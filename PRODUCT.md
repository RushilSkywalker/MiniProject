# GraphQuery
<!-- impeccable:product-schema 1 -->
## Platform
web
## Stack
User specified React/Vite, Tailwind, Express, TypeScript, OpenAI, Neo4j, and Zod.
## Users
E-commerce shoppers searching for products by budget, ratings, reviews, availability and required features. Also used as a VTU mini-project demonstration.
## Product Purpose
Search an e-commerce catalog with natural-language product requirements using an inspectable question → generation → independent review → planning → results workflow.
## Capabilities and Constraints
Credential-free deterministic demo and explicitly configured live integrations. No authentication, automatic seeding, silent demo fallback, or fabricated live results. Actual live schema arrives later. Demo uses fictional products, INR prices, rating summaries, selected verified reviews, categories and features.
## Accessibility & Inclusion
Keyboard access, labeled controls, readable contrast, responsive layout, explicit asynchronous states.
## Decisions delegated in the brief
Proceed without credentials or clarification. Assumed use scene: a laptop in a classroom demonstration. Visual decisions are implementation choices, not user preferences.
